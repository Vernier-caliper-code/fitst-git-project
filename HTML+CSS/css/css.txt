1. 内联和内部样式表 外部样式表
    内联：
        <p style="color: pink"> </p> 
    内部： （放在head标签内）
        <style>
        div {
            color: blue;
        }

        strong {
            color: purple;
        }
        </style>
    外部： （放在head标签内）
        <link rel="stylesheet" href="./css/style.css" ">

2. 基础选择器： 类型选择器  类选择器  ID选择器 通配符选择器

        类型选择器：
            在head标签内
            <style>
                p {
                    color：blue；
                }
                
            </style>

        类选择器：
            在heaad标签内
            <style>
                .red {
                    color：red；
                }
            </style>

            在body标签内
            <p class="red"></p>

        ID选择器： 他和类选择器一样，但是ID选择器只能选择一个元素
            在head标签内
            <style>
                #red {
                    color：red；
                }
            </style>

            在body标签内
            <p id="red"></p>

        通配符选择器：
            在head标签内
            <style>
                * {
                    color：red；
                }
            </style>
            

3.补充知识点:
    * {
      margin: 0;
      /* 清除所有元素的外边距 */
      padding: 0;
      /* 清除所有元素的内边距 */
    }

    /* 让块级盒子在浏览器中水平居中对齐 */
        .center {
          margin: 0 auto;
        }




4. 关系选择器：  后代选择器   子代选择器   邻接兄弟选择器  通用兄弟选择器
      后代选择器：
          <style>
              div p {
                  color：red；
              }
          </style>

      子代选择器：
          <style>
              div > p {
                  color：red；
              }
          </style>

          <div>

        邻接兄弟选择器：
            <style> 
                div + p {
                    color:red;
                }

        通用兄弟选择器：
            <style> 
                div ~ p {
                    color:red;
                }

5.css文本样式： 字体样式 文本布局
        字体样式：color  font-size  font-family font-style font-weight text-decoration
            1.color:开发使用#FF0000（十六进制），特殊情况用rgb()/rgba()文字透明
               <style>
                   p {
                       color: red;
                   }
                   p {
                       color: #FF0000;
                   }
                   h1 {
                       color: rgb(255, 0, 0);
                   }
               </style>
               
             2.font-family: 开发中一般选择的是无衬线字体
               <style>
                   p {
                       font-family: Arial, Helvetica, sans-serif;
                   }
               </style>

              3.font-size: 默认16px
               <style>
                   p {
                       font-size: 16px;
                   }
               </style>

               4.font-style: normal关闭斜体  italic设置斜体 
                   <style>
                       p {
                           font-style: italic(normal);
                       }
                   </style>

               5.font-weight: normal(400) 关闭加粗  bold(700) 设置加粗 
                  <style> 
                       p {
                           font-weight: 400(700);
                       }
                   </style>

              **6.text-decoration: none 关闭下划线  underline 设置下划线  line-through 设置删除线
                   <style> 
                       p {
                           text-decoration: none;
                       }
                   </style>
        文本布局： line-height  text-align  text-indent  letter-spacing（字符之间的间距）  
                 1.text-align: left  center  right  justify(自动改变字间距，两端对齐)  
                     <style> 
                         p {
                             text-align: center;
                         }
                     </style>

                 2.text-indent: 2em 缩进
                     <style> 
                         p {
                             text-indent: 2em;
                         }
                     </style>

                3.letter-spacing: 2px
                    <style> 
                         p {
                             letter-spacing: 2px;
                         }
                     </style>

                4.line-height: 一般用于垂直居中 （行高和盒子的高度一样）
                    <style> 
                         p {
                             line-height: 1.5;
                         }
                     </style>

6. font 简写 ： font-size/line-height font-family  注意这样是有严格的书写顺序的
        <style> 
             p {
                 font: 16px/1.5 Arial, Helvetica, sans-serif;
             }
         </style>

   css 继承特性：   子元素会继承部分父元素的样式 ，比如说 字体 颜色   

7.分组选择器： 当多个元素具备相同的样式的时候，使用分组选择器将不同的选择器组合在一起。
        <style> 
             p,h1,h2,h3,h4,h5,h6 {
                 color: red;
             }
         </style>

8.伪类选择器：
    链接伪类选择器；开发中一般只用link和visted，而且要注意写的顺序  link（初始） visited（已访问链接） hover（鼠标悬停） active（点击但是没有松开）
          <style> 
               a:link {
                   color: red;
               }
               a:visited {
                   color: blue;
               }
               a:hover {
                   color: yellow;
               }
               a:active {
                   color: green;
               }
           </style>
    
    状态伪类选择器：用户以某种方式和文档交互的时候应用   ：focus(点击之后的聚焦) :hover(悬停)
             <style> 
               .box {
                   width: 200px;
                   height: 200px;
                   background-color: red;
                   color: white;
                   
               }
               .box:focus {
                   background-color: yellow;
                   color: red;
               }
               .box:hover {
                   background-color: blue;
                   color: yellow;
               }
           </style>

    结构伪类选择器： :first-child  :last-child  :nth-child(odd/even)  
           <style> 
                .uli li:first-child {
                    color: red;
                }
                .uli li:last-child {
                    color: blue;
                }
                .uli li:nth-child(odd) {
                    color: yellow;
                }
           </style>
  
        

    表单伪类选择器：
        用途： 1.表单按钮禁用的时候，调整颜色。 2.复选框选中修改样式 :disabled :checked
            <style> 
                botton:disabled {
                    background: gray;
                    opacity: .4;
                }
                input:checked+lable {
                    background-color: red;
                }
            </style>
    伪元素选择器：::first-line ::first-letter ::placeholder  ::before  ::after
            <style>
            /* 选择首行 */
            p::first-line {
            color: #ff6900;
            }

            /* 选择首字母 */
            p::first-letter {
            color: red;
            font-size: 28px;
            }

            textarea {
            color: pink;
            font-size: 14px;
            }

            textarea::placeholder {
            color: red;
            font-size: 12px;
            }

            /* before和after伪元素 */
            div::before {
            content: '我是';
            color: red;
            }

            div::after {
            content: '老师';
            color: red;
            }
        </style>

    属性选择器： 
          [属性名]
          [属性名=属性值]
          [属性名^=属性值]
          [属性名$=属性值]
          [属性名*=属性值]
           
            <!DOCTYPE html>
            <html lang="en">

            <head>
            <meta charset="UTF-8">
            <meta name="viewport" content="width=device-width, initial-scale=1.0">
            <title>属性选择器</title>
            <style>
                a {
                color: #000;
                text-decoration: none;
                }

                /* 属性选择器 */
                /* 1. 选择包含属性 */
                /* a[class] {
                color: red;
                } */

                /* 2. 选择属性等于值  完全匹配 */
                /* a[class="font"] {
                color: red;
                } */

                /* 3. 选择属性值以xx开头 */
                /* a[class^="font"] {
                color: red;
                } */

                /* 4. 选择属性值以xx结尾 */
                /* a[class$=t14] {
                color: red;
                } */

                /* 5. 选择属性值包含xx */
                a[class*="font"] {
                color: red;
                }

                input[type="text"],
                input[type="password"] {
                /* 去掉轮廓线 */
                outline: none;
                }
            </style>
            </head>
