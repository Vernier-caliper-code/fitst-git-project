# 项目重难点速查

> 本文档提炼 documentation-helper 项目三个核心文件（ingestion / core / main）的重难点，用于快速回顾。
> 区分「设计亮点」（值得学、面试可讲）与「坑」（跑不通、需注意）。

## 三文件重难点总表

| 文件 | 核心重难点 | 性质 |
|------|-----------|:---:|
| **ingestion.py** | ① 异步分批（`asyncio.gather`）并发入库 | 设计亮点 |
| | ② `metadata.source` 贯穿整条引用链 | 设计亮点 |
| | ③ ⚠️ 写 **Chroma**，查询端是 **Pinecone** | 坑 |
| **core.py** | ④ `content_and_artifact` 双份返回 | **最精妙** |
| | ⑤ Agent 模式（自主检索）vs 传统 Chain | 设计亮点 |
| | ⑥ 遍历所有 `ToolMessage` 收集 artifact | 设计亮点 |
| | ⑦ ⚠️ 索引名 `langchain-docs-2026`、模型 `gpt-5.2` | 坑 |
| **main.py** | ⑧ Streamlit 重跑模型 + `session_state` | 重难点 |
| | ⑨ 把 `run_llm` 的 `{answer, context}` 接进 UI | 关键 |
| | ⑩ ⚠️ 无对话记忆（README 宣称但没实现） | 坑 |

---

## ingestion.py —— 数据怎么进来

```
[爬取 Tavily] → [Document(page_content, source)] → [切块] → [异步批量入库]
```

- **① 异步入库（最难）**：`切批 → 每批一个协程 → asyncio.gather 并发 → return_exceptions=True 容错 → 统计成功数`。
  - **为什么并发？** 因为嵌入很慢，瓶颈从「总工作量」变成「最慢单个任务」。
  - **通用模板**：以后批量调 API / 批量爬取都复用这套。
- **② `metadata.source`**：`metadata["source"]=url` 后来被 retrieve_context 读出、`_format_sources` 提取，最终显示为回答下方的「Sources」。**没有它，引用来源是空的。**
- **坑 ⚠️**：实际用 **Chroma**（本地）入库，和查询端的 **Pinecone** 对不上。

---

## core.py —— RAG 大脑

```
create_agent(模型, [retrieve_context工具]) → LLM自主决定检索 → 生成回答 → 收 artifact
```

- **④ `content_and_artifact`（全项目最精华）**：工具同时返回两份——
  - **content**（纯文本）→ 喂 **LLM**（生成回答）
  - **artifact**（原始 Document）→ 给 **程序**（提取 source URL 展示）
  - **一份数据两个消费者**：LLM 要可读文本，main.py 要结构化对象。
- **⑤ Agent 模式**：检索变成 Agent 的能力，LLM 自主决定查 0/1/多次，而非固定 Chain。
- **⑥ 提取结果**：
  - `answer = response["messages"][-1].content` 取**最后一条** AI 消息（Agent 可能多轮调工具）。
  - 遍历**所有** ToolMessage 收 artifact（可能多次检索）。**不能只拿最后一个。**
- **坑 ⚠️ ⑦**：索引名 `langchain-docs-2026`、模型 `gpt-5.2` 不存在。

---

## main.py —— 前端薄壳

```
[UI输入] → 调 run_llm → 显示 answer + 折叠的 Sources → 存回 session_state
```

- **⑧ Streamlit 重跑模型**：**每次交互重跑整个脚本** → 对话历史必须存 `session_state` 才不丢。先渲染历史消息 → 再追加新消息。
- **⑨ 数据接入**：`run_llm(prompt)` 返回 `{answer, context}`——一个给正文，一个过 `_format_sources` 给来源。
- **坑 ⚠️ ⑩**：无对话记忆（README 宣称但没实现）；同步阻塞。

---

## 三文件串联数据流（一条线记住）

```
ingestion.py（离线跑一次）
   Tavily爬官网 → 切块 → 嵌入 → 存【Chroma】⚠️
                │
                ▼（查询时）
main.py ──调run_llm──▶ core.py
                          │ create_agent → retrieve_context工具
                          ▼
                     从【Pinecone】查（⚠️对不上）→ 生成回答 → {answer, context}
                          │
main.py: answer→正文, context→Sources
```

## 三组「互为镜像」的坑（重看务必记住）

1. **向量库**：ingestion 写 **Chroma** ⇄ core 查 **Pinecone** → **查空**
2. **模型名**：core 用 `gpt-5.2`（不存在）→ **直接报错**
3. **README vs 代码**：README 宣称 Pinecone + 对话记忆 → **代码实际 Chroma + 无记忆**。**以代码为准，别信 README。**

## 一句话收尾

- **ingestion** 把文档变向量（数据入口）
- **core** 用 Agent + 双份返回工具做检索生成（RAG 大脑，最值得学 `content_and_artifact`）
- **main** 用 Streamlit 把结果变成聊天 UI（薄壳，最先学 `session_state` 和重跑模型）
